Redoslijed rada – šta se postavlja prvo, korak po korak

Ovo je kratki spisak redoslijeda. Svaki korak kaže gdje kliknete (AutoCAD: kartica VANJSKO UREĐENJE PRO → ploča → dugme; SketchUp: meni Extensions → Vanjsko uređenje PRO), a u zagradi je naredba za kucanje. Objašnjenja s primjerima su u Prvi projekat, sve opcije u Priručniku.

Zlatno pravilo: redoslijed je jedinica → ishodište → nulta kota → slojevi → preuzimanje → kote → teren → crtanje → provjera → izvoz. Ako se preskoči korak koji je ranije na spisku, kasniji koraci daju pogrešne mjere ili visine.

Najkraći put (novo): Prvi koraci (ploča Projekat) otvara spisak od 8 koraka koji se sami štikliraju – dvoklik na korak ga pokreće. Novi projekat je jedan prozor. Ulicu cijelog profila crta Ulica, raskrsnicu Kružni tok, a cijeli list s oznakama, legendom i tabelama pravi Dokumentuj list. Kad naredba traži tip, otvara se lista sa slikama i pretragom; širine i brojevi se mogu pisati sa zarezom (4,5).

0. Jednom, na početku (instalacija)

  1. AutoCAD: zatvorite AutoCAD → raspakujte VanjskoUredjenjePRO-AutoCAD-instalacija.zip → pokrenite INSTALIRAJ.bat → pokrenite AutoCAD. Mora se pojaviti kartica VANJSKO UREĐENJE PRO.
    • Ako se kartica ne pojavi, ukucajte SDPABOUT. Ako javi Unknown command, instalacija nije uspjela (v. Instalacija).
  2. SketchUp: Extensions → Extension Manager → Install Extension → odaberite pb_site_design_pro.rbz → ponovo pokrenite SketchUp. Mora se pojaviti meni Extensions → Vanjsko uređenje PRO i traka alata.
    • Ako traka alata nije vidljiva: View → Toolbars → Vanjsko uređenje PRO.

A. Vaš projekat „Situacija 29.10." (već pretvoren u paket)

Paket situacija-vanjsko-uredjenje.sdpkg već ima jedinicu (cm), ishodište i ±0,00 = 504,00 m n.v. Koraci 1–8 iz dijela B ovdje se ne rade; to je urađeno pri pretvaranju.

#Gdje kliknutiŠta uraditi / odgovoriti
A1AutoCAD: File → NewPrazan crtež (šablon acadiso.dwt). Ne uvozite u crtež koji već ima elemente drugog projekta.
A2Ploča SketchUp razmjena → Uvoz paketa (SDPUVOZPAKETA)Odaberite situacija-vanjsko-uredjenje.sdpkg.
A3Pitanje INSUNITS … Postaviti INSUNITS na cm?Da
A4Kucajte ZOOM → EVidi se cijela situacija.
A5File → Save AsSnimite kao DWG, npr. Situacija_VU.dwg. To je vaš projekat.
A6Ploča Projekt → Postavke (SDPSETTINGS)Provjerite: jedinica Centimetri, naziv projekta. Ništa ne mijenjajte ako nije potrebno.
A7Ploča Teren i kote → Nulta kota (SDPDATUM)Samo provjera: ±0,00 = 504,00. Ako arhitekta da drugu vrijednost, ispravite ovdje.
A8Ploča 3D modeli → Uredi element (SDPEDIT)Ispravite pretpostavke iz izvještaja konverzije (redom ispod).
A9Nastavite od koraka B9 (projektovanje)Dalje je isto kao za svaki projekat.

Pretpostavke koje se ispravljaju prve (korak A8):

  1. Objekti: pomoću SDPSELECT označite objekte, pa Uredi element → Visina i Broj etaža po stvarnom projektu. Sada je visina = broj etaža × 3,00 m.
  2. Popločanje: maslinasta šrafura je uvezena kao Betonsko popločanje. Ako je kamen ili ploče, u **Uredi element** promijenite Materijal, ili obrišite element i nacrtajte pravu vrstu po istoj konturi (SDPCONVERT na konturu).
  3. Zidovi i žardinjere: upišite stvarne visine (Visina, kod žardinjera Visina zida).
  4. Stabla: prečnik krošnje je veličina simbola (1,12 m). Označite stabla (SDPSELECT → po vrsti) → Uredi element → Prečnik krošnje, Visina (pri sadnji).
  5. Mala rampa: provjerite smjer uspona (izvještaj konverzije).
  6. Igrališta: upišite proizvod i visine sprava (Uredi element → svojstva i Visina).

D. Kad se projekat promijeni (uvijek ovim redom)

  1. Izmjena u AutoCAD-u (najčešće): izmijenite element (gripovi ili Uredi element) → Provjeri projekat → Izvoz paketa u istu datoteku → u SketchUpu ponovo Uvoz paketa... u isti model. Mijenjaju se samo izmijenjeni elementi.
  2. Izmjena u SketchUpu: u SketchUpu izmjene u Svojstva elementa → zatim Izvoz izmjena za AutoCAD... → u AutoCAD-u SketchUp razmjena → Primijeni izmjene (SDPAPPLYCHANGES) → zatim ponovo Izvoz paketa.
  3. Paket napravljen drugdje (npr. pretvoren iz drugog DWG-a): Uvoz paketa (SDPUVOZPAKETA) u prazan crtež (dio A).
